What is HTML?

❮ ❯ 🌐 ❮ / ❯

HTML stands for HyperText Markup Language and it is the standard language used to create web pages. It provides the basic structure of a webpage by using tags to define elements like headings, paragraphs, images, and links. HTML tells the browser what content to display and how to organize it on the screen. It works together with CSS for styling and JavaScript for interactivity.

✔ Semantic Elements ✔ Forms & Inputs ✔ Tables & Lists ✔ Multimedia
